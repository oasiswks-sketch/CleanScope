# CleanScope 2.0 · 商业化升级与收费功能方案

## 1. 商业目标

CleanScope 2.0 不与传统清理软件比“能扫多少垃圾”，而是占据一个更窄、
更有付费意愿的位置：

> 为 AI 重度用户、开发者和内容创作者解释 Mac 上现代工具链的空间占用，
> 并把重复判断沉淀为可信的清理规则。

首个商业版本的目标不是订阅收入最大化，而是建立三种信任：

1. 扫描结果可信：所有结论有路径与证据。
2. 删除边界可信：免费用户也能看到完整风险说明。
3. 付费理由可信：Pro 收费的是效率、历史和规则，不是把安全信息藏起来。

## 2. 目标用户

### 核心用户

- 同时使用 Codex、Claude、Trae、WorkBuddy 的 AI 开发者
- 本地使用 Whisper、Ollama、LM Studio、Hugging Face 的创作者
- 经常安装 Python、Node、FFmpeg、Manim、Playwright 环境的技术用户
- 需要解释“系统数据”和卸载残留的高级 Mac 用户

### 次级用户

- 小型工作室和开发团队
- 负责清理演示机、测试机、构建机的技术支持人员
- 经常在多个 Mac 之间切换的独立开发者

## 3. 产品层级

### CleanScope Free

永久免费，建立信任和口碑：

- 完整扫描七类空间来源
- 查看路径、容量、风险、权限、识别依据与删除影响
- Finder 定位
- 单项或最多 3 项批量移入废纸篓
- 永久删除的二次确认
- 完全磁盘访问引导
- 所有安全边界完整可见

### CleanScope Pro Personal

建议首发价：`¥128` 一次买断；正式价：`¥198`。

- 智能清理方案：根据风险、更新时间、来源与可再生成本排序
- 无限批量清理
- 清理历史、累计释放空间和最近操作记录
- 自定义排除路径
- 一键选择可再生缓存
- 未来 2.x 的规则库更新
- 最多 3 台个人 Mac

### CleanScope Pro Team（2.1 规划）

建议：`¥699 / 年 / 10 台 Mac`。

- 团队排除规则
- 扫描报告导出
- 清理策略模板
- 构建机 / 测试机快速基线
- 优先支持

## 4. 收费原则

- 不用恐惧营销，不显示虚构“健康分”。
- 不把风险解释、路径或删除影响锁在付费墙后。
- 不在用户准备删除时突然拦截；免费额度在选择阶段清楚提示。
- 默认移入废纸篓，付费用户也不能绕过不可逆确认。
- 一次买断优先，符合独立 Mac 工具的使用频率与信任预期。

## 5. 2.0 已实现范围

### 商业基础

- P-256 签名的离线许可证
- 公钥内置 App，私钥不进入 GitHub
- 许可证激活、状态展示与停用
- Free / Pro 功能边界
- Pro 商业升级页

### Pro 功能

- 智能清理计划
- 按安全性与时间排序的建议列表
- 一键选中计划
- 清理历史和累计节省
- 自定义排除
- 无限批量处理

### 免费功能调整

- 保留完整扫描和完整证据
- 保留单项与小批量清理
- 选择超过 3 项时解释 Pro 价值，不破坏当前选择

## 6. 转化路径

1. 用户完成第一次扫描。
2. 总览直接展示“可安全处理”的真实空间，不制造虚构分数。
3. 用户进入“智能方案”，预览推荐依据和预计释放容量。
4. 免费用户可以继续手动处理；Pro 用户一键应用完整方案。
5. 清理完成后写入历史，让长期价值在下一次打开时可见。

## 8. 商业上线依赖

软件的许可证验证可以独立工作。自动收款与自动发证仍需品牌方提供以下任一
支付渠道账号：

- Lemon Squeezy / Paddle / FastSpring
- Stripe Checkout + Cloudflare webhook
- Mac App Store 非消耗型内购

在支付账号接入前，可以用私有授权工具手动签发创始用户许可证。私钥必须保持
离线，不得提交 GitHub 或放进 App 包。
