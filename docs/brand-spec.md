# CleanScope 2.0 · Brand Spec

## 品牌定位

CleanScope 是“空间侦察器”，不是夸大性能焦虑的“系统医生”。品牌需要传达：

- 清晰：把复杂占用拆解为可以理解的来源
- 克制：不自动删除，不制造风险恐惧
- 精密：像专业仪器一样给出证据和边界
- 本地优先：数据不离开这台 Mac
- 面向未来：真正理解 AI 工具链

品牌主张：

> 看清每一 GB，再决定删什么。

商业版辅助主张：

> 把反复判断，交给可信的规则。

## 视觉系统

### 主色

- Mineral Mint：`#69D7B4`，表示安全、已验证、可执行
- Glacier Blue：`#72C7F4`，表示路径、组件与系统信息
- Warm Amber：`#E9B85C`，表示需要判断但不是危险
- Signal Coral：`#E97B75`，仅用于不可逆操作和受保护项目

### 中性色

- Graphite 950：`#0B1016`
- Graphite 900：`#101820`
- Graphite 800：`#18222B`
- Graphite 700：`#26343E`
- Mist 100：`#EAF0EE`
- Mist 300：`#A9B5B2`

### 使用规则

- 不使用紫色渐变作为“科技感”捷径。
- 不用霓虹 glow、速度表、火箭、垃圾桶作为主视觉。
- 色彩必须表达风险、类别或状态，不能只为装饰。
- 主要内容背景保持温暖石墨色，降低冷蓝 SaaS 模板感。
- 次要文字对比度不得低到需要“猜”。

## 排版

- App：以系统字体保证 macOS 一致性与可访问性，数字使用 rounded design。
- 官网 Display：高对比、紧凑字面，正文保持舒适行长。
- 中文使用「」而非英文直引号。
- 一级信息要短，解释放在二级层，不在一张卡里塞满三个结论。

## 布局

- App 使用三栏工作区：导航 / 工作台 / 证据详情。
- 商业功能是新的工作模式，不是覆盖在清理按钮上的广告。
- Pro 状态和升级入口可见但克制，不遮挡扫描结果。
- 删除确认永远位于动作之后，不能被付费弹窗替代。

## 动效

- 扫描：用一次连续的“建立索引”状态表达，不做循环炫光。
- 列表：只在新增或移除项目时使用短暂位移与淡化。
- 清理完成：数字和状态更新，不使用庆祝粒子。
- 遵循“减少动态效果”，不把运动作为唯一反馈。
